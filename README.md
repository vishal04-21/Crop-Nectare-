🌾 CropNectar – AI/ML Based Crop Prediction System
📘 Project Overview

CropNectar is an AI and Machine Learning–based project designed to help farmers and agriculture students identify the most suitable crop to grow based on soil and environmental conditions.
The system uses real agricultural data and applies the Random Forest Classifier algorithm to make accurate crop predictions.

Users can input values such as Nitrogen (N), Phosphorus (P), Potassium (K), Temperature, Humidity, pH, and Rainfall, and the system instantly predicts the best crop for those conditions.

This project was developed as part of an MCA 3rd Semester AI/ML Course under the guidance of Prof. Anand Singh Jalal at the School of Computer Science and IT.

🚀 Features

Predicts the best crop to grow based on soil and climate data.

Simple and interactive web interface built using Flask, HTML, and CSS.

Machine learning model trained using Random Forest Classifier.

Dataset sourced from Kaggle – Crop Recommendation Dataset.

Beginner-friendly code, easy to run and understand.

🧠 Technologies Used

Python 3

Flask (for backend)

HTML, CSS (for frontend)

Scikit-Learn (for ML model)

Pandas, NumPy (for data handling)
